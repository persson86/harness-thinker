# vault-heuristics.md

Opcional. Registre heurísticas de decisão destiladas do usuário para priorização, recomendação, arquitetura de páginas e trade-offs.

Formato sugerido: `quando [condição] -> prefira [decisão] porque [razão]`.

Exemplo: `quando uma nota mistura execução e autoconhecimento -> preservar o fato em source e mover a síntese para insight`.
