# Thinker One Page

Leia `harness/operations/one-page.md` no root do vault e siga a operação. Conte as palavras com `bash harness/scripts/one-page-count.sh <arquivo>`.

Mostre a página primeiro na tela, com as Notas fora dela, e salve o rascunho em `drafts/one-page/`. Exporte só quando o usuário pedir: use o destino de documento que a sessão expuser; sem isso, grave HTML ou MD em `output/one-page-<slug>/` e diga o caminho. Não presuma recurso que a sessão não mostra.
