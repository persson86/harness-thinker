# Thinker Delegate

Leia `harness/operations/delegate.md` no root do vault. A interface é `python3 harness/scripts/delegate.py`; o manual condicional está em `harness/delegation.md`.

Instrução explícita do usuário vence preferência de sessão e padrão. A extensão pode chamar uma CLI de outro provedor; não traduzir nomes como Luna ou Sonnet para um modelo Grok. Luna low é o padrão inicial de Git, se a CLI Codex estiver disponível. Falha de disponibilidade devolve a decisão, sem substituição silenciosa.

O Grok permanece interlocutor desta sessão quando for o principal. Recupere a inbox nos turnos pertinentes, revise contribuições e preserve edições humanas. Não prometa notificação nativa de um processo externo. Instalação não ativa a feature e não autoriza commit/push.
